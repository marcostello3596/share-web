# SHARE — sitio web

Sitio one-page de SHARE, agencia de marketing (Mendoza).

## Estructura

- `index.html` — todo el sitio (HTML + CSS + JS en un solo archivo)
- `share -1.svg` — logo
- `share -2.svg` — fondo glitch
- `share-bg.mp4` — video del hero
- `DSC00876.jpg` — foto del equipo
- `logos-clientes/` — logos de clientes para la marquesina

## Ver el sitio

Abrir `index.html` en el navegador. No requiere build ni dependencias.
